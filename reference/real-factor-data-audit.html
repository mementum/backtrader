两种财务生效口径

模式有效日期含义
snapshot-safemax(notice, update) 后下一交易日不提前使用当前版本，但旧报告会非常陈旧
notice-date首次公告日后下一交易日覆盖率高，但可能把后续修订值带回首次公告日

notice-date 运行后应统计 update_date > signal_date 的行数；任何一行都代表当前版本在该信号日尚不存在。

每次运行必须检查

  1. 每月股票数量和缺失原因。
  2. report_date ≤ notice_date ≤ effective_date ≤ signal_date。
  3. valuation_date ≤ signal_date < entry_date < exit_date。
  4. UPDATE_DATE > NOTICE_DATE 的观察比例。
  5. 所用财报距离信号日的年龄。
  6. 历史股票池、行业分类和退市股是否按当时状态保存。
  7. 开发样本与保留样本是否方向一致。

停止信号

  • 当前快照按首次公告日回填，却声称完全 point-in-time。
  • 固定使用今天仍上市的股票回测过去，却忽略幸存者偏差。
  • 保留样本失败后反转因子方向，再继续引用同一个保留样本。
  • 免费数据覆盖不足时，用零填充 PE、ROE 或市值。
  • 因子没有稳定预测力，却直接进入 Backtrader 调参。
